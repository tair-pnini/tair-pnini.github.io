# tair-pnini.github.io

האתר של תאיר פניני – https://tair-pnini.github.io

## מבנה התיקיות

| תיקייה | מה יש בה |
|---|---|
| `/` | `index.html` (דף הבית), `join.html`, דפי הפנייה של קמ"ל, ו-`404.html` (הדף שמוצג בכל כתובת שלא קיימת, עם קישור לדף הבית) |
| `gifted-plc/` | קהילות מקצועיות לומדות – אגף א' למחוננים ומצטיינים (`index.html`), `math/` דף ההרשמה של קמ"ל מתמטיקה ו-`riddle.html`, `assets/` לוגואים ותמונת שיתוף. `_source/` (PDF, סרטון, סקריפט Apps Script) לא עולה לגיטהאב |
| `math/` | הוראת מתמטיקה בבית הספר (`y10/`, `y11/` וכלים כלליים) |
| `gifted/ai/` | חומרי הוראת AI; `play-ai-2026/` – עבודות תלמידים |
| `gifted/python/` | חומרי פייתון (בהמשך) |
| `gifted/oranim/` | ארכיון – מדריכי אורנים |
| `riddles/` | חידות |
| `games/` | משחקים |
| `sandbox/` | ניסויים מהירים |

## כללים

- **לא להזיז את `join.html`** – הקישור אליו כבר בשימוש.
- **`kamal-gifted-math.html` ו-`gifted-kml-math-2027.html` הם דפי הפנייה** אל `/gifted-plc/math/`. לא למחוק ולא לשים בהם תוכן.
- לדפים שהועברו בארגון מחדש (ספטמבר 2026) אין הפניות – הכתובות הישנות שלהם כבר לא עובדות.
