כלל הברזל: איך מוצאים את גורם השינוי (q)?

📈 גדילה באחוזים: מוסיפים את אחוז השינוי ל-1
q = 1 + (p / 100)
דוגמה: מחיר מניה עלה ב-15% ← מוסיפים ל-1: q = 1 + 0.15 = 1.15
📉 דעיכה באחוזים: מחסירים את אחוז השינוי מ-1
q = 1 - (p / 100)
דוגמה: מחיר רכב ירד ב-20% ← מורידים מ-1: q = 1 - 0.20 = 0.80
💡 מסקנה מהירה: אם q > 1 זו גדילה | אם 0 < q < 1 זו דעיכה!
